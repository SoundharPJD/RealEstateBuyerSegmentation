# 🏠 Real Estate Buyer Segmentation

Real Estate Buyer Segmentation is a machine learning project that uses
K-Means clustering to group real estate buyers into different segments.

## 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

## 🤖 Machine Learning

This project uses **K-Means Clustering** to identify groups of buyers
based on their characteristics.

## 📊 Features

- Buyer segmentation
- Segment analysis
- Data visualization
- Buyer segment prediction
- Interactive Streamlit dashboard
